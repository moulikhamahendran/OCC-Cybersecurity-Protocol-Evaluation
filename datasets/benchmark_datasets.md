# Benchmark Datasets

This document summarizes benchmark datasets used for cybersecurity evaluation, industrial communication analysis, and protocol validation.

---

## Purpose

Benchmark datasets provide standardized environments for evaluating:

- MQTT
- OPC UA
- DDS
- Industrial communication security
- Intrusion detection systems
- Cyber-physical system resilience

---

## Dataset Overview

| Dataset | Domain | Use Case |
|---------|--------|-----------|
| MQTT-IoT-IDS2020 | MQTT / IoT | Intrusion Detection |
| MQTTset | MQTT | Attack Classification |
| TON_IoT | IIoT | Cybersecurity Benchmark |
| Edge-IIoTset | Industrial IoT | Network Attack Detection |
| SWaT | ICS / SCADA | Industrial Control Security |
| BATADAL | Water ICS | Cyberattack Simulation |
| CARLA | Autonomous Vehicles | Communication Validation |
| KITTI | Autonomous Systems | Sensor Benchmark |

---

## Dataset Details

### MQTT-IoT-IDS2020
- Focus: MQTT-based attacks
- Usage: Intrusion detection validation
- Type: Network traffic
- Domain: IoT cybersecurity

### MQTTset
- Focus: MQTT communication under attacks
- Usage: Classification and anomaly detection
- Type: Packet-level traffic

### TON_IoT
- Focus: Telemetry and network traffic
- Usage: IIoT cybersecurity analysis
- Type: Multi-source telemetry

### Edge-IIoTset
- Focus: IIoT network communication
- Usage: Cyberattack detection
- Type: Industrial network traffic

### SWaT
- Focus: Industrial process monitoring
- Usage: ICS anomaly detection
- Type: Sensor + PLC traffic

### BATADAL
- Focus: Water distribution cyberattacks
- Usage: Infrastructure attack analysis
- Type: Industrial control data

### CARLA
- Focus: Autonomous driving simulation
- Usage: Communication validation
- Type: Vehicle simulation

### KITTI
- Focus: Autonomous vehicle sensing
- Usage: Benchmark comparison
- Type: Vision + telemetry

## Dataset Evaluation Goals

Datasets are used to:

- Measure protocol resilience
- Evaluate anomaly detection
- Validate cybersecurity models
- Simulate industrial traffic
- Benchmark autonomous communication

Datasets were selected based on:

- Public availability
- Industrial relevance
- Cybersecurity focus
- Communication protocol support
- Research reproducibility
