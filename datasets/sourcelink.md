# Dataset Source Links

This document lists datasets, repositories, and benchmark resources used for protocol evaluation, cybersecurity analysis, and industrial communication research.

---

## MQTT Datasets

### MQTT-IoT-IDS2020
- Description: Intrusion detection dataset for MQTT-based IoT traffic
- Usage: Attack detection, anomaly analysis
- Link: https://sites.google.com/view/iot-network-intrusion-dataset

### MQTTset Dataset
- Description: Dataset containing MQTT network traffic under attack scenarios
- Usage: Cyberattack classification
- Link: https://github.com/bhassani/MQTTset

---

## ICS / SCADA Datasets

### SWaT Dataset
- Description: Secure Water Treatment industrial control dataset
- Usage: ICS anomaly detection
- Link: https://itrust.sutd.edu.sg/itrust-labs_datasets/dataset_info/

### BATADAL Dataset
- Description: Water distribution cyberattack dataset
- Usage: Industrial attack analysis
- Link: https://batadal.net/

## Industrial IoT Datasets

### TON_IoT Dataset
- Description: Telemetry and IoT attack dataset
- Usage: Cybersecurity validation
- Link: https://research.unsw.edu.au/projects/toniot-datasets

### Edge-IIoT Dataset
- Description: Industrial IoT communication traffic dataset
- Usage: Protocol analysis and IDS validation
- Link: https://ieee-dataport.org/open-access/edge-iiotset-cyber-security-dataset-iot-and-iiot-applications
