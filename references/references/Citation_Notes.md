# Citation Notes

## Citation Style

IEEE citation format is used throughout the research.

## Example Citation

[1] Author Name, “Paper Title,” Journal Name, vol. x, no. x, pp. xx–xx, Year.

## Citation Management Notes

- Zotero can be used for reference management
- DOI should be stored whenever available
- Conference and journal papers should be separated

## Preferred Sources

- IEEE journals
- Elsevier journals
- Springer conference papers
- ACM proceedings

## Avoided Sources

- Blogs
- Non-peer-reviewed websites
- Marketing articles
- Unverified whitepapers
