# KPI Definitions

## Key Performance Indicators

| KPI | Description |
|---|---|
| Latency | Communication delay |
| Jitter | Variation in communication delay |
| Throughput | Data transfer rate |
| Packet Loss | Percentage of lost packets |
| Resilience | Ability to continue operation during attacks |

## Importance

The KPIs are used to measure cybersecurity protocol performance in OCC systems.

## Expected Evaluation Areas

- Normal operation
- High traffic load
- Attack conditions
- Multi-node communication
- Wireless communication environments
