# Findings Summary

## Literature Review Findings

### DDS Security

- Lowest latency
- High throughput
- Strong real-time capability

### MQTT TLS

- Lightweight architecture
- Higher latency due to TLS overhead
- Suitable for telemetry systems

### OPC UA Security

- Strong industrial compatibility
- Balanced performance and security
- Suitable for ICS environments

## Common Findings

- Security mechanisms increase communication overhead
- Real-time systems require low-latency secure communication
- Attack resilience differs across protocols

## Key Observation

Security-performance trade-offs are critical in OCC-based systems.
