# Systematic Literature Review Methodology

## Review Type

This research follows a systematic literature review methodology.

## Databases Used

- IEEE Xplore
- Scopus
- Web of Science
- SpringerLink

## Review Process

1. Search execution
2. Duplicate removal
3. Title screening
4. Abstract screening
5. Full-text review
6. Final paper selection

## Inclusion Criteria

- Cybersecurity-related papers
- OCC, Industry 4.0, ICS, or SCADA systems
- Real-time communication systems
- Peer-reviewed journal or conference papers
- Papers discussing latency, throughput, jitter, resilience, or performance

## Exclusion Criteria

- Non-technical papers
- Duplicate studies
- Irrelevant application domains
- Books without technical evaluation
- Non-peer-reviewed sources

## Purpose

The SLR is intended to identify research gaps, protocol trends, cybersecurity challenges, and evaluation methodologies suitable for OCC architectures.
