# Project Overview

## Title

Cybersecurity Middleware Framework for Operational Control Center (OCC) Architectures in Autonomous and Industrial Systems

## Objective

The objective of this internship research is to investigate secure communication protocols and evaluate their performance in OCC-based autonomous and industrial environments.

The work focuses on cybersecurity, resilience, and real-time communication requirements in Industry 4.0 systems.

## Main Focus Areas

- DDS Security
- MQTT with TLS
- OPC UA Security
- VDA 5050

## Application Domains

- Autonomous vehicles
- Intralogistics
- Industrial Control Systems (ICS)
- SCADA systems
- Cyber-Physical Systems

## Key Goals

- Build conceptual cybersecurity middleware framework
- Define measurable KPIs
- Compare communication protocols
- Analyze protocol behavior under attack conditions
- Design OCC dashboard architecture
- Develop prototype implementation using Raspberry Pi and ESP32

## Expected Outcome

A framework capable of evaluating secure communication protocols in safety-critical OCC environments using measurable cybersecurity and performance indicators.
