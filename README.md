# OCC Cybersecurity Middleware Framework

This project demonstrates an initial Raspberry Pi-based OCC cybersecurity prototype.

Current features:
- MQTT broker using Mosquitto
- Vehicle telemetry simulator
- Middleware subscriber
- Streamlit OCC dashboard
- Cyber attack simulation
- KPI monitoring: latency, speed, battery, packet loss, jitter, threat events

Hardware:
- Raspberry Pi 5

Week 1 progress:
- Raspberry Pi setup completed
- MQTT communication working
- Dashboard working
- Attack simulation started
