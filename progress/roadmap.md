# Research Roadmap

This document outlines the complete roadmap for the research project.

---

## Research Objective

To evaluate and compare MQTT, OPC UA, and DDS communication protocols for cybersecurity, performance, and industrial applicability in autonomous and industrial environments.

---

## Research Workflow

```text
Literature Review
        ↓
PRISMA Screening
        ↓
Paper Shortlisting
        ↓
Research Gap Identification
        ↓
Protocol Comparison Framework
        ↓
KPI Definition
        ↓
Dataset Collection
        ↓
Experimental Design
        ↓
Testbed Setup
        ↓
Protocol Benchmarking
        ↓
Cybersecurity Evaluation
        ↓
Performance Analysis
        ↓

        ↓
Conclusion and Recommendations
```

## Roadmap Phases

### Phase 1 — Literature Foundation
- Define research scope
- Conduct database search
- Perform PRISMA screening
- Create literature matrix

---

### Phase 2 — Methodology Development
- Define evaluation metrics
- Create KPI framework
- Establish comparison methodology
- Identify datasets

---

### Phase 3 — Experimental Setup
- Design testbed
- Configure protocols
- Establish network environment
- Implement security settings

---

### Phase 4 — Evaluation
- Execute protocol tests
- Measure KPIs
- Apply attack simulations
- Record protocol behavior

---

### Phase 5 — Analysis
- Compare results
- Identify trade-offs
- Validate findings
- Generate visualizations

---

### Phase 6 — Thesis Completion
- Write findings
- Build conclusion
- Add recommendations
- Final review
