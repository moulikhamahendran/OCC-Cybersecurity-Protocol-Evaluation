# Archived DDS Pilot / Legacy Material

This directory contains historical DDS material that must **not** be used as
the FAIR-V1 formal DDS implementation.

## Why it was archived

The historical DDS security policy was built around the pilot topic:

- `OCCVehicleState`

The formal FAIR-V1 DDS application uses:

- `fair_v1_vm001_telemetry`
- `fair_v1_vm001_echo`

The historical security generator created publisher/subscriber identities.
The formal FAIR-V1 Step-9 repair instead uses dedicated DDS-domain identities
for:

- Micro XRCE-DDS Agent-created Fast DDS participant
- Raspberry Pi OCC DDS participant

Formal FAIR-V1 DDS remains under:

- `testbed/hardware/esp32/dds/formal/`
- `testbed/hardware/raspberrypi/dds/formal/`

The frozen FAIR-V1 specification remains authoritative.

## Status

- Historical/pilot only.
- Do not relabel as FAIR-V1 formal data or implementation.
- Do not use these archived security policies for C1/C2 formal runs.
- Historical results are preserved separately and are not deleted by this archive operation.
